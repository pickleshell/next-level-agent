# NLA Source Provenance

Next Level Agent is an independent project. Its skills foundation was sourced
from [Superpowers](https://github.com/obra/superpowers) at commit
`b36e0829c6d0140e93cfef2ca599b1b07d4a7797`. There is no planned upstream
synchronization.

NLA-specific engineering includes the OpenCode coordinator and roles, bounded
model pools and failover, structured memory, Assistant Notebook integration,
controlled compaction/restoration, Compactor prompt and tool-schema
optimization, capability caching, telemetry, installation guidance, and NLA
tests.

Inherited source remains covered by [`LICENSES/SUPERPOWERS.txt`](LICENSES/SUPERPOWERS.txt).
NLA-specific source is covered by [`LICENSE`](LICENSE).
